# NRV DRONE WAR

Основа проекта Roblox Studio + Rojo. Сейчас это **заготовка**, а не готовая игра.

## Уже добавлено
- `default.project.json` — карта синхронизации Rojo.
- `src/shared/DroneCatalog.lua` — каталог Scout, Ranger и Titan с игровыми характеристиками.
- `src/shared/GameConfig.lua` — стартовые настройки.
- `src/server/Bootstrap.server.lua` — начальные значения игрока на сервере.
- `src/client/Welcome.client.lua` — тестовая надпись на экране.

## Дальше
1. Проверить синхронизацию Rojo с Roblox Studio на компьютере.
2. Подключить безопасное FPV-управление и управление с телефона.
3. Сделать 3D-гараж, выбор дронов и прокачку.
4. Добавить карту, испытания, косметику и постоянное сохранение.

На компьютере: установить Rojo и его плагин для Studio, в папке репозитория выполнить `rojo serve default.project.json` и подключить плагин. Эти файлы пока не изменяют опубликованную Roblox-игру автоматически.
